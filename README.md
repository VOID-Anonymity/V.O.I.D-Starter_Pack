# 🌑 V.O.I.D Starter Pack

## 🗡 Возможности артефакта

Скрипт проводит путника через несколько этапов инициации:

* **⚡ Ускорение (Optimization):** Внедрение `zRAM` (алгоритм zstd) и перевод CPU в режим `Performance`.
* **🌐 Окно в Бездну (Browsers):** Выбор и установка защищенных браузеров (`LibreWolf`, `Brave`, `Chromium`).
* **🍷 Темное искусство (Wine):** Воскрешение сущностей `.exe` через Wine и настройка шрифтов.
* **📦 Потоки сокровищ (Downloads):** Установка торрент-клиентов `qBittorrent` или `Gopeed`.
* **🎭 Завеса невидимости (VPN):** Развертывание инструментов обхода цензуры (`Throne`, `v2rayA`, `Hiddify`).
* **📡 Скрытый стук:** Автоматическое уведомление мастера о запуске скрипта через зашифрованный воркер.

## 📜 Ритуал запуска

Для активации скрипта в своей обители, используй следующие заклинания:

```bash
# Стянуть свиток из архива
git clone https://github.com/VOID-Anonymity/V.O.I.D-Starter_Pack.git
cd V.O.I.D-Starter_Pack

# Даровать право на исполнение
chmod +x Starter-pack.sh

# Начать обряд (требуются права Властелина)
sudo ./Starter-pack.sh
